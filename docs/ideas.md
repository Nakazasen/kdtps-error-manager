# 💡 Ideas - KDTPS Error Manager

## Mục tiêu chính

Thay thế việc nhập lỗi vào 3 file riêng biệt (File cơ 4, File KDTPS, SharePoint) bằng **1 phần mềm duy nhất**.

## User Stories

### 👔 Leader

- [ ] Lấy dữ liệu từ file KDTPS hàng ngày
- [ ] Chọn phòng & sheet để lưu
- [ ] Gán người phụ trách cho từng điểm vấn đề
- [ ] Gửi mail thông báo cho người phụ trách

### 👷 NPT (Người phụ trách)

- [ ] Nhập nội dung điều tra (cột N)
- [ ] Dịch nhanh các đoạn text (Nhật ↔ Việt)
- [ ] Gửi mail trả lời KDTPS khi hoàn thành

### 📊 Báo cáo

- [ ] Thống kê lỗi mới/đã xong/tồn đọng theo loại máy
- [ ] View lỗi đang điều tra
- [ ] View lỗi cần JP hỗ trợ
- [ ] Backup lỗi hoàn thành
- [ ] Tìm kiếm lịch sử lỗi

## Ý tưởng mở rộng (Future)

- Dashboard real-time
- Thống kê trend lỗi theo thời gian
- Notification khi có lỗi mới
- Mobile view (web-based)
- Integration với SharePoint API
